J.A.R.V.I.S.

Política de privacidad · Vigente desde el 29 de septiembre de 2026

JARVIS es un asistente de voz personal y privado: lo usa únicamente su dueño, en su propia computadora y en su propio celular. No es un servicio público, no tiene otros usuarios y no se vende.

Qué datos de Google usa

Solo con el permiso expreso del dueño, JARVIS puede leer su Google Calendar, su Gmail (leer y crear borradores; nunca envía correos), sus contactos, sus pendientes de Google Tasks y sus archivos de Google Drive, únicamente para responder lo que el propio dueño le pide.

Dónde se guardan

El acceso a la cuenta queda cifrado en la computadora del dueño. JARVIS no tiene servidores propios ni bases de datos en internet, y no guarda copias de correos ni documentos fuera de esa computadora.

Con quién se comparten

Con nadie. Para entender y responder, el contenido que el dueño pide consultar se procesa con la API de Gemini de Google. Los datos no se venden, no se usan para publicidad y no se transfieren a terceros.

Uso de datos de las API de Google

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El dueño puede quitar el acceso cuando quiera desde myaccount.google.com/permissions o desconectando la cuenta desde JARVIS.
